# LEXORA - AI Career Roadmap Generator

LEXORA is an AI-powered Career Roadmap Generator that helps students and professionals discover the skills, projects, and career paths required for various technology roles.

## Features

- AI Engineer Roadmap
- Machine Learning Engineer Roadmap
- Data Scientist Roadmap
- Data Analyst Roadmap
- Cloud Engineer Roadmap
- DevOps Engineer Roadmap
- Cybersecurity Analyst Roadmap
- UI/UX Designer Roadmap
- Product Manager Roadmap

## Tech Stack

- Python
- Gradio
- Hugging Face Spaces

## Live Demo

https://huggingface.co/spaces/Jslxh/lexora-ai

## Installation

```bash
pip install -r requirements.txt
python app.py
```
